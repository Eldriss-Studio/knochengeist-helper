# Knochengeist

A ghost in the Godot editor. Ask it anything about Godot, and it points at each click.

## How to ask

Press Option+G (Alt+G off a Mac) and type your question. If the answer needs clicks, press Show me.

## Which AI tool

The ghost answers through an AI tool you already use: Claude Code, Codex or GitHub Copilot. You sign in with your own plan. Pick the tool in the ghost's menu, under Settings.

## The full guide

It covers what each question sends and how to install the AI tools. Read it at https://github.com/Eldriss-Studio/knochengeist-helper.
